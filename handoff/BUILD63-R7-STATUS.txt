Sample inventory, and what was not removed
No shipped script assigns a stable sample plant id. emptyState() starts with empty plants and empty motherFatherPlants. index.html does not load build61.js, b57-fixture.js, or the qa/shot scripts. Those files still contain synthetic names used only by tests and screenshots. They are not a running creation path.
build58.js still has placeholder text "e.g. Rocco OG" and "e.g. Rocco Seeds" on an empty input. That is hint text, not a record, and it has no id. It was not treated as a plant to delete.
build61.js still contains a name-matched comment and landrace test. index.html does not load it, so it does not run. It was not edited.
wide.js and build58.js comments mention example strain names. Comments do not create records.
A saved record whose name is Rocco, or any other name, has no source id that marks it as a sample. It is left in place. This patch does not hide it and does not claim the production sample is gone.
