Before any QA launch:

  zsh rig-guard.sh <QA App.app> mac

The mac check reads running apps with lsappinfo and System Events. It blocks when the bundle id is exactly com.borikengenetics.logbookapp, including a renamed .app or an iOS-on-Mac wrapper whose executable is App. com.borikengenetics.logbookapp.qa is not that id. If either query fails, or a Logbook-like app has no readable bundle id, the check stops. It does not quit or launch the production app.

Designed-for-iPad UI tests are unsupported in Xcode, so that runner is not the way to launch QA. Leave it unrun.
