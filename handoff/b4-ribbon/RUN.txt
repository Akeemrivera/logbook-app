Family-tree ribbon. Public fixture only. No private records.

The tree block reserves padding-bottom of the tab bar height plus
env(safe-area-inset-bottom). On a tall phone the same grandparents,
parents, plant circle, and name ribbon (including the subtitle) are
tightened so they sit above the bar at the initial scroll. The eight
styles and their branches stay. The backup banner and other pages are
not restyled. The worker cache name is v94 so a cache-first install
loads the new stylesheet; the fetch behavior is the v93 worker.

Copy this folder onto the machine, then from the app root:

  node /path/to/b4-ribbon/b63-ribbon-patch.js .

Expect, before the patch, on the current tree3 files:

  node scripts/b63-tree-ribbon.test.js

to fail the 390x844 ribbon (it sits under the tab bar, and the tree
block has no bottom reserve). Apply the patch, then run the same
command. It uses the harness Chrome flags
--disable-extensions and --disable-component-extensions-with-background-pages.
Eight styles at 390x844 must pass at the initial scroll, and 375x667
and 1024x768 must clear the bar without horizontal overflow.

The 16-check acceptance is unchanged:

  node scripts/b63-real-mockup.test.js

A local check that does not need the app:

  node b63-tree-ribbon.test.js --self
